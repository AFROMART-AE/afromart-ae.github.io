# AFROMART GENERAL TRADING L.L.C Website

A responsive corporate static website created for AFROMART GENERAL TRADING L.L.C, Dubai, UAE.

## Files
- `index.html` — main website
- `styles.css` — responsive styling
- `script.js` — mobile navigation and current year
- `assets/logo.png` — supplied AFROMART logo

## Run locally
Open `index.html` in a browser.

## Publish
Upload all files/folders to any static hosting provider or web server, keeping the `assets` folder beside `index.html`.


QUALITY & HYGIENE CONTENT
The website now highlights AFROMART's long-standing African foodstuffs, beverages and cosmetics experience, HACCP certification, and emphasis on hygienic handling and packing of applicable food products.
